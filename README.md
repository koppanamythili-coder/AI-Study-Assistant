# AI Study Assistant

A simple student-focused learning web application built with Python and Flask.

## Features
- Ask questions about basic technical topics
- Practice a short quiz
- Generate a 5-day study plan
- Simple and responsive web interface

## Technology Stack
Python, Flask, HTML, CSS, JavaScript

## Run locally
1. Install Python.
2. Open a terminal in this project folder.
3. Run `pip install -r requirements.txt`
4. Run `python app.py`
5. Open `http://127.0.0.1:5000` in a browser.
